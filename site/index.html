How it works

Claude finishes. Clausper starts talking before you've looked up.

Every reply goes through the same four beats. The order matters, so they're numbered.

01

The turn ends

A hook sees the reply the moment Claude stops. Short replies are spoken as they are, with no wait at all.

0 ms
02

The opening line is spoken

For long replies, Clausper reads the first sentence at once while Haiku writes a two-sentence summary through your own session.

≈ 1–2 s
03

The summary and the ask

You hear what changed and what needs your decision. The spoken sentence shows as a caption above the prompt.

sentence by sentence
04

“What next?”

Clausper listens, stops at your pause, transcribes on your Mac, and sends your words as the next prompt.

≈ 0.3 s to transcribe
Features

Built for people who'd rather listen than read 150 lines.

Spoken summary

Two or three sentences on what was done and how it turned out, written for the ear. File names are said in words.

macOS system voice

Live captions

The sentence being spoken shows above the prompt and in the pane, in sync with the voice. Turn them off with one command.

/clausper captions

What changed, clickable

Every file Claude edited or wrote, and every command it ran. Press one to see its diff, open it in your editor, or copy its path.

git diff · open · copy

Listen mode

Hands-free. Say “cancel” to skip a turn, or use fill mode to put your words in the prompt box and check them before sending.

sox + whisper.cpp, local

No API key

Summaries come from Haiku through your Claude Code session, so they run on the subscription you already pay for.

$.model.complete

Private by design

Recording and transcription happen on your machine. The only network call is the one Claude Code already makes.

nothing uploaded
Install

One line in Claude Code. Two more if you want to talk back.

Clausper is a Claude Code mod. The repository is private for now, so you need access on GitHub and a git credential on your machine.

# at the Claude Code prompt
/plugin install clausper --marketplace kenawak/clausper

# listen mode (optional): recorder, transcriber, model
brew install sox whisper-cpp
mkdir -p ~/.clausper/models
curl -L -o ~/.clausper/models/ggml-base.en.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.en.bin

# then, back in Claude Code
/clausper setup
/clausper listen auto
macOS asks for microphone access the first time Clausper listens. Allow it for your terminal app. Speech needs macOS; the pane and captions work anywhere Claude Code runs.
/clausperOpen the pane
/clausper mute · unmuteSilence or restore speech
/clausper againRepeat the last summary
/clausper stopCut speech off
/clausper captions on · offShow or hide the caption line
/clausper listenListen once, right now
/clausper listen auto · fill · offHands-free, prompt box only, or never
/clausper voice SamanthaPick a system voice; voices lists them
/clausper setupCheck the listening tools
