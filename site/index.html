After the summary Clausper asks “What next?”, beeps, records until you pause, transcribes on your Mac, and sends the words as your prompt. Say “cancel” to skip a turn.

Install one line, two more for voice input

Clausper is a Claude Code mod. One line installs it from the public repository; two more set up voice input.

# at the Claude Code prompt
/plugin install clausper --marketplace kenawak/clausper

# listen mode (optional): recorder, transcriber, model
brew install sox whisper-cpp
mkdir -p ~/.clausper/models
curl -L -o ~/.clausper/models/ggml-base.en.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.en.bin

# then, back in Claude Code
/clausper setup

Questions before you install

Does it cost extra?

No. Summaries are written by Haiku through your own Claude Code session, so they count against the subscription you already have. There is no API key to buy and no account to create.

Where does my voice go?

Nowhere. Recording uses sox and transcription uses whisper.cpp, both running on your Mac with a model stored in your home folder. Clausper adds no network calls of its own.

Will it read me the whole reply?

No, that is the point. Short replies are read as they are. Long ones get the opening sentence at once, then a two-sentence summary plus anything Claude asked you. The full text stays in the terminal.

What if it mishears me?

Say “cancel” to skip a turn. Use fill mode and Clausper puts your words in the prompt box instead of sending them, so you can check them first. The pane shows what it heard and for how long.

Does it work on Linux or Windows?

The pane, captions and change list work anywhere Claude Code runs. Speech uses the macOS system voice today, and listening is tested on macOS. Linux speech is on the list.

Can I pick the voice?

Yes. Run /clausper voices to list every voice installed on your Mac and /clausper voice Samantha to choose one. The choice is remembered.
